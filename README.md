# sql-sales-analysis
## Overview
Analyzed sales data using SQL to extract meaningful business insights.

## Tools Used
- SQL Server (SSMS)

## Key Analysis
- Calculated total sales and profit
- Analyzed sales by region
- Identified top customers
- Tracked monthly sales trends
- Found loss-making transactions

## Key Insights
- Certain regions generated higher revenue
- A few customers contributed most sales
- Some transactions resulted in losses
